SkyPulse | Weather Forecast Application

SkyPulse is a web-based weather application developed using Python and Flask. It provides real-time weather information and a 5-day forecast through a simple, responsive, and user-friendly interface.

Overview

The application enables users to search for weather conditions by city and view essential weather information. It integrates with a weather API to retrieve data and presents it through a dynamic interface.

Key Features

- Current Weather: View temperature, humidity, and weather conditions.
- 5-Day Forecast: Explore upcoming weather forecasts.
- City Search: Retrieve weather information for different cities.
- Recent Searches: Quickly revisit recently searched cities.
- Dynamic Interface: Weather-based backgrounds for an engaging user experience.

Installation and Setup

1. Clone this repository.

2. Navigate to the project directory.

3. Install the dependencies:
   
   "pip install -r requirements.txt"

4. Configure your OpenWeather API key using an environment variable or a local ".env" file.

5. Start the application:
   
   "python weather_app.py"

6. Open the local URL displayed in your terminal.

Environment Configuration

Store your API key securely in a local ".env" file. Never commit API keys, passwords, or other secrets to the repository.
